4. Explicación del Código y Justificación de Decisiones Analíticas

Cumpliendo la recomendación #4 del docente: Código en texto con explicación en palabras propias de cada decisión tomada.

A. Función de Regresión Logística y Score

function predictLogistic(hypotension, platelets, pcv, alt, wbc) {
    // 1. Transformación binaria basada en cortes ROC
    const x_hypo = hypotension ? 1 : 0;
    const x_plaq = platelets <= 75000 ? 1 : 0;
    const x_pcv = pcv >= 42.0 ? 1 : 0;
    const x_alt = alt >= 70 ? 1 : 0;
    const x_wbc = wbc >= 7000 ? 1 : 0;

    // 2. Score de severidad discreto (Suma ponderada según coeficientes divididos por 0.94)
    const score = (x_hypo * 3.0) + (x_plaq * 1.0) + (x_pcv * 1.0) + (x_alt * 1.0) + (x_wbc * 1.0);

    // 3. Ecuación del Logit (Z) y Sigmoide continua
    const z = -3.85 + (3.0 * x_hypo) + (1.16 * x_wbc) + (1.07 * x_alt) + (1.06 * x_plaq) + (0.94 * x_pcv);
    const probability = 1 / (1 + Math.exp(-z));

    return { score, probability };
}
Justificación de la decisión tomada: Se utilizó una función sigmoide estándar para convertir el valor $Z$ en una probabilidad acotada entre $0$ y $1$. Los coeficientes provienen de la regresión logística multivariada ajustada por los Odds Ratios del estudio ($OR = 20.11$ para hipotensión implica un coeficiente alto de $+3.0$).

B. Implementación de la Red Neuronal (Forward Propagation)

function predictANN(hypotension, platelets, pcv, alt, wbc) {
    const inputs = [
        hypotension ? 1.0 : 0.0,
        platelets <= 75000 ? 1.0 : 0.0,
        pcv >= 42.0 ? 1.0 : 0.0,
        alt >= 70 ? 1.0 : 0.0,
        wbc >= 7000 ? 1.0 : 0.0
    ];

    // Propagación hacia adelante en capa oculta (ReLU)
    const hiddenOutputs = [];
    for (let i = 0; i < 4; i++) {
        let sum = biasesHidden[i];
        for (let j = 0; j < 5; j++) {
            sum += inputs[j] * weightsHidden[i][j];
        }
        hiddenOutputs.push(Math.max(0, sum)); // Función de Activación ReLU
    }

    // Salida Neuronal con Activación Sigmoide
    let outputSum = biasOutput;
    for (let i = 0; i < 4; i++) {
        outputSum += hiddenOutputs[i] * weightsOutput[i];
    }
    return 1 / (1 + Math.exp(-outputSum));
}
Justificación de la decisión tomada: Se diseñó un Perceptrón Multicapa (MLP) de 3 capas (5 entradas, 4 neuronas ocultas y 1 salida). Se eligió la activación **ReLU** en la capa oculta porque evita la saturación de gradientes y permite capturar las interacciones complejas entre la fuga plasmática (hematocrito) y la vasculopatía grave.
