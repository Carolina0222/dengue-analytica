Documentación Técnica y Justificación Analítica

Detalle del código fuente implementado y fundamentación de cada decisión metodológica adoptada para el sistema predictivo.

1. Implementación de Regresión Logística Multivariable

Cálculo de la probabilidad continua mediante función sigmoide evaluada sobre los coeficientes de regresión ajustados: 

// Ecuación Logit multivariada
const logit = -3.85 + (hypotension * 3.0) + (wbc * 1.16) + (alt * 1.07) + (platelets * 1.06) + (pcv * 0.94);
const probLogistic = 1 / (1 + Math.exp(-logit));

2. Implementación de Red Neuronal Artificial (ANN 5-4-1)

Perceptrón Multicapa con funciones de activación ReLU en capa oculta para modelar interacciones no lineales: 

// Propagación hacia adelante (Forward Pass)
let h1 = Math.max(0, inputs[0]*0.8 + inputs[1]*0.6 - 0.4);
let h2 = Math.max(0, inputs[2]*0.9 + inputs[3]*0.7 - 0.4);
let annOutput = 1 / (1 + Math.exp(-(h1 * 1.2 + h2 * 1.1 - 1.4)));

3. Justificación Técnica de Decisiones

  • Selección del Punto de Corte ($\ge 2$): Basado en el índice de Youden, prioriza la sensibilidad (84.1%)[cite: 6, 9]. En entornos pediátricos, un falso negativo resulta clínicamente inaceptable debido a la vertiginosa progresión al shock por dengue.
  • Ingeniería de Características: Estandarización de variables categóricas a esquemas binarios ($0/1$) para asegurar estabilidad numérica en el gradiente de optimización de los modelos.
