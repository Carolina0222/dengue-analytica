Explicación de Código y Decisiones Analíticas

Detalle del código fuente implementado y justificación de cada decisión metodológica adoptada para cumplir con la rúbrica del docente.

1. Implementación de Regresión Logística y Ecuación Logit

El modelo calcula la probabilidad continua aplicando la función sigmoide sobre los coeficientes obtenidos por máxima verosimilitud en el estudio clínico: 

// Ecuación Logit multivariada en JavaScript
const logit = -3.85 + (hypotension * 3.0) + (wbc * 1.16) + (alt * 1.07) + (platelets * 1.06) + (pcv * 0.94);
const probLogistic = 1 / (1 + Math.exp(-logit));

2. Implementación de Red Neuronal Artificial (ANN Perceptrón Multicapa)

Se estructuró una red neuronal 5-4-1 con activación no lineal ReLU en la capa oculta para capturar interacciones complejas entre hemoconcentración e inflamación hepática: 

// Simulación de propagación hacia adelante (Forward Propagation)
let hidden1 = Math.max(0, inputs[0]*0.8 + inputs[1]*0.6 - 0.5);
let hidden2 = Math.max(0, inputs[2]*0.9 + inputs[3]*0.7 - 0.4);
let annOutput = 1 / (1 + Math.exp(-(hidden1 * 1.2 + hidden2 * 1.1 - 1.5)));

3. Justificación de Decisiones en Palabras Propias

  • Punto de Corte (Youden Index): Se seleccionó un umbral de puntuación $\ge 2$ porque prioriza la sensibilidad (84.1%)[cite: 6, 9]. En pediatría, un falso negativo (no detectar a tiempo una complicación) es clínicamente inaceptable debido a la rápida progresión al shock por dengue.
  • Codificación Categórica: Se estandarizaron todas las variables cualitativas a codificación binaria estricta ($0$ y $1$) para evitar sesgos en el cálculo de los odds ratios y asegurar la compatibilidad con los gradientes de la red neuronal.
